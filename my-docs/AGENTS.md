# my-docs — Fumadocs documentation site

## Quick start

```bash
npm install        # postinstall → fumadocs-mdx codegen
npm run dev        # dev server at http://localhost:3000
npm run build      # static export to out/
```

## Commands

| Command | What it does |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Static export to `out/` |
| `npm run start` | Serve `out/` (`serve` package, not Next.js) |
| `npm run lint` | ESLint (next/core-web-vitals) |
| `npm run types:check` | `fumadocs-mdx && next typegen && tsc --noEmit` |

## Codegen

`.source/` is generated by `fumadocs-mdx` and gitignored. Run it before typechecking or when content changes aren't reflected:

```bash
npx fumadocs-mdx
```

Postinstall runs it automatically.

## Architecture

- **App name** in `src/lib/shared.ts` (used as nav title)
- **Content**: MDX in `content/docs/` with frontmatter (title, description, etc.)
- **Source loader**: `src/lib/source.ts` — `fumadocs-core/source` loader from `.source/`
- **Routes**:
  - `/` — docs pages (catch-all `[[...slug]]`)
  - `/api/search` — static Orama search
  - `/og/docs/[...slug]` — OG images
  - `/llms.txt`, `/llms-full.txt` — LLM text output
  - `/llms.mdx/docs/[...slug]` — raw markdown
- **Shared layout**: `src/lib/layout.shared.tsx` — both home and docs layouts
- **Search**: Static Orama via `src/components/search.tsx`
- **MDX components**: `src/components/mdx.tsx`

## Path aliases

- `@/*` → `src/*`
- `collections/*` → `.source/*`

No test framework is configured.
