PISO Maps API cung cấp quyền truy cập lập trình vào dữ liệu Google Maps thông qua ba endpoint: **Autocomplete**, **Search** và **Place Detail**.

## Bắt đầu

1. Truy cập dashboard và đăng ký bằng email của bạn.
2. Sao chép **API key** từ dashboard.
3. Thêm nó vào header `x-api-key` trong mỗi yêu cầu API.

Thử một cuộc gọi:

```bash
curl "https://api.piso.dev/api/maps/autocomplete?q=highland&lat=10.801671&lng=106.61744" \
  -H "x-api-key: YOUR_API_KEY"
```
