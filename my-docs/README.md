# PISO Maps API Documentation

Documentation site for the PISO Maps API — covers 3 endpoints: **Autocomplete**, **Local Results**, and **Place Detail**. Built with Next.js + Fumadocs, bilingual English/Vietnamese, statically exported.

## Overview

- **Endpoints documented**: Autocomplete, Local Results, Place Detail
- **Authentication**: API key sent via `x-api-key` header (register at [Registration URL] to get a key)
- **Design**: Runwai design system — monochrome palette, Inter font, weight 400 headings
- **i18n**: English (`en`) and Vietnamese (`vi`)
- **Search**: Static Orama search index

## Prerequisites

- Node.js
- npm

## Commands

| Command | Description |
|---------|-------------|
| `npm install` | Install dependencies (postinstall runs `fumadocs-mdx` codegen) |
| `npm run dev` | Start dev server at `http://localhost:3000` |
| `npm run build` | Static export to `out/` (22 pages) |
| `npm run start` | Serve `out/` locally |
| `npm run lint` | ESLint |
| `npm run types:check` | Codegen → typegen → TypeScript check |

## Project Structure

```
content/docs/          MDX documentation files (.en.mdx / .vi.mdx)
  api-docs/            Endpoint pages + meta files
src/app/
  [lang]/              Locale route group
    (docs)/            Docs layout + catch-all page
  api/search/          Orama search route handler
  og/docs/             OG image generation
  llms.mdx/docs/       Raw markdown output
src/lib/               Config (i18n, source loader, shared options, theme)
src/components/        Search dialog, MDX components, providers
.source/               Generated by fumadocs-mdx (gitignored)
```

## Codegen

`.source/` is gitignored. After adding/changing content files, regenerate:

```bash
npx fumadocs-mdx
```

Postinstall runs it automatically.

## i18n

- `dot` parser: `file.en.mdx` / `file.vi.mdx`, `meta.vi.json`
- `hideLocale: 'never'` — URLs always include locale prefix (`/en/...`, `/vi/...`)
- No middleware (static export compatible)
- Language switcher in the UI sidebar

## Build

```bash
npm run build
```

Output in `out/`. Preview with `npm run start`.

## Tech Stack

- Next.js 16 (static export)
- Fumadocs (content source, UI components)
- Runwai design (CSS variables over Fumadocs `black.css` base theme)
- Tailwind CSS
- Orama (static search)
- Shiki (code highlighting, `vitesse-light`/`vitesse-dark` themes)
